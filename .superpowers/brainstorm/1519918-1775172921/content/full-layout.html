Legenda dos elementos interativos

PLAN (azul)
Card colapsável com plano de implementação. Botões: Aprovar, Rejeitar, Editar.
PERMISSÃO (amarelo)
Mostra o comando/ação. Botões: Permitir, Negar, Permitir sempre.
TOOL (cinza)
Tool result colapsável. Mostra nome da tool + arquivo. Expandir para ver detalhes.
PERGUNTA (roxo)
Pergunta do Claude com opções clicáveis ou campo de texto livre.
